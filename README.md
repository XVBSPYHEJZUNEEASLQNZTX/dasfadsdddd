# NTC — лёгкий клиент для Android

Приложение просто открывает https://ntc.party во встроенном WebView.

- Единственное разрешение — `INTERNET`
- Ни одной зависимости (нет AndroidX, аналитики, рекламных SDK)
- Сторонние куки отключены, запросы к известным трекерам и рекламным сетям блокируются
- Ссылки не на ntc.party открываются во внешнем браузере
- Кнопка/жест «назад» ходит по истории страниц, вход в аккаунт сохраняется
- Тёмная/светлая тема по системной
- Android 13+ (minSdk 33), target 36

## Строгий режим
В `MainActivity.java` есть константа `STRICT_THIRD_PARTY`. По умолчанию `false`.
Если поставить `true`, со всех сторонних сайтов будут разрешены только картинки.
Приватнее, но форум может сломаться, если берёт скрипты или стили с чужого CDN.

## Как получить APK (GitHub, ничего не нужно устанавливать)
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (папки `app` и `gradle` перетаскивайте мышкой целиком).
2. Вкладка **Actions** → **set up a workflow yourself** → вставьте содержимое файла `.github/workflows/build.yml` → Commit.
3. Дождитесь зелёной галочки и скачайте `ntc-apk` из раздела **Artifacts**.

APK подписан debug-ключом. Перед установкой новой сборки удаляйте старую: ключ каждый раз новый.
